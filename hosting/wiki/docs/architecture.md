# 容器隔離與配額機制 (Architecture & Security)

Craft-Core Hosting 採用高安全性的容器隔離架構，確保每個用戶應用運行在獨立的 Docker 容器內，資源互不影響。

---

## 資源隔離與限制

系統對每一個容器實施 CPU 與記憶體硬性邊界限制：

- **CPU 配額限制**：根據設定的 CPU 比例限制算力資源（最高 100% CPU）。
- **記憶體限額限制**：當容器記憶體使用超過分配上限時（例如 512MB），系統會防止進程干擾其他應用。
- **SSD 磁碟限制**：每台容器擁有獨立受控之硬碟寫入配額。

---

## 網路與反向代理

- **內部隔離**：容器內部預設無法直接暴露公開 Port，維護安全隔離。
- **8 位專屬域名與 SSL 自動加密**：一鍵開啟對外 Port 後，系統會為容器自動核發 8 位英數隨機專屬域名 (例: `app-a8k2m9x1.hosting.craft-core.xyz`)，並由 Caddy 提供 HTTPS SSL 安全加密存取。
