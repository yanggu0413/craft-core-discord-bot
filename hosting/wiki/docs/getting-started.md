# 快速上手指南 (Quick Start Guide)

歡迎使用 **Craft-Core Hosting 容器託管平台**。本指南將協助您完成帳號登入、建立第一台 Docker 機器，並開通網頁存取。

---

## 1. 帳號登入

Craft-Core Hosting 採用 Discord 安全驗證：

1. 點擊登入頁面的 **「使用 Discord 帳號登入 / 免費開始使用」**。
2. 授權登入後即可直接進入控制台管理您的 Docker 機器與工作區。

---

## 2. 建立第一台 Docker 託管機器

在儀表板點擊 **「+ 建立新託管機器」** 按鈕，填寫以下參數：

| 欄位名稱 | 說明與規範 | 範例 |
| --- | --- | --- |
| **專案名稱** | 容器識別名稱 (僅限小寫英數與 dash) | `discord-bot-service` |
| **執行環境 (Runtime)** | 支援 `Node.js 22 (LTS)` 或 `Python 3.11` | `Node.js 22 (LTS)` |
| **部署來源** | 可選擇 **GitHub Repo URL** 或上傳 **ZIP 部署包** | `https://github.com/user/repo` |
| **啟動指令 (CMD)** | 容器啟動時執行的命令 | `node index.js` 或 `python main.py` |
| **內部 Port** | 應用程式在容器內監聽的連接埠 | `3000` |
| **CPU / RAM 配額** | 調整該容器分配到的 CPU 比例與記憶體上限 | `50% CPU / 512MB RAM` |

---

## 3. 個人資源限制規範

為確保容器隔離與穩定性，平台實施資源配額管理：

- **機器數量上限**：每位用戶最多可建立 **2 台** Docker 機器。
- **CPU 配額總和**：所有機器加總不可超過 **100% CPU**。
- **記憶體限額總和**：所有機器加總不可超過 **1024 MB (1GB RAM)**。
- **硬碟空間限額總和**：所有機器加總不可超過 **4096 MB (4GB Disk)**。

---

## 4. 自動核發對外 Port 與 8 位專屬 SSL 域名

若您的機器需要對外提供 HTTP API 或網頁服務：

1. 在機器專案「設定」頁面中點擊 **「自動開啟對外 Port」**。
2. **無需管理員審核**，系統將秒級自動配發 8 位隨機英數專屬子域名與對外 Port：
   ```http
   https://app-a8k2m9x1.hosting.craft-core.xyz
   ```
3. 您可以隨時點擊 **「刪除 Port」** 釋放資源，或點擊 **「重新核發 Port 與域名」** 替換全新的 8 位專屬域名。
