# 🔐 箱子密碼鎖保險箱指南

為了保護您的貴重財產，Craft-Core 提供了 **箱子密碼鎖系統**。您可以為個人的箱子設定專屬密碼，防止未經授權的玩家開啟。

---

## 🎮 開啟與使用方式

您可以使用以下指令或透過選單開啟：

```bash
# 開啟密碼箱管理
/padlock

# 選單快捷入口
/menu -> 點選 [🌿 領地與密碼箱]
```

---

## 💡 核心功能說明

1. **🔒 建立與設定密碼**：
   - 對著您要鎖定的箱子執行 `/padlock`，設定您專屬的數字或英文字母密碼。
   - 鎖定成功後，非信任玩家開啟箱子時將被要求解鎖。

2. **🔑 輸入密碼解鎖**：
   - 當您或受邀朋友開啟帶鎖箱子時，系統會開啟解鎖選單，正確輸入密碼後即可存取物品。

3. **👥 信任成員授權**：
   - 您可以將隊友或信任的玩家加入保險箱的信任名單中，讓他們可以直接存取而無需每次輸入密碼。
