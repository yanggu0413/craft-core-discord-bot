# 🛡️ 領地內生物與實體保護規範

Craft-Core 提供了全面的 **「領地生物與實體保護 (Claim Entity Protection)」**。當您使用 `/claim` 劃分領地後，領地內的生物與物品實體將獲得完整保護！

---

## 🔒 保護對象與受限行為

非領地成員（未獲得 `interact` 互動權限或非領地擁有者/OP）在他人領地內將受以下嚴格保護限制：

### 1. ⚔️ 禁止傷害生物與實體 (Damage Protection)
- **受保護生物**：牛、羊、豬、雞、馬、狼、貓、村民、鐵傀儡等所有玩家飼養或繁殖之生物。
- **受保護物品實體**：盔甲架 (Armor Stand)、物品展示框 (Item Frame) 等。
- **傷害攔截範圍**：包含近戰揮劍、揮拳、遠程弓箭、三叉戟、投擲傷害藥水、煙火與玩家引爆之 TNT。
- *若無權限嘗試傷害，系統將自動中斷並發出警示：`§c[Craft-Core] 領地保護：您無權傷害玩家 領地內的生物/物品！`*

### 2. 🤝 禁止未授權互動 (Interaction Protection)
- 非領地成員無法在領地內進行未授權的生物互動：
  - ✂️ 剪羊毛 / 擠牛奶
  - 🐴 騎乘馬匹 / 駱駝
  - 🌾 繁殖生物 / 餵食
  - 🛍️ 與村民進行交易

---

## ⚙️ 如何授權好友互動

若您希望與好友共建農場或共享村民交易所，可於遊戲內或網頁端授權好友權限：

- **遊戲內指令**：
  ```bash
  /claim grant <好友玩家名> interact
  ```
- **網頁端權限設定**：在 Web Dashboard 的 [領地保護設定](Web-Claims-Management.md) 頁面勾選好友的 `Interact (互動)` 權限即可！
