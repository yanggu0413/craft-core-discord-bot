# 📦 虛擬快遞箱系統指南

在 Craft-Core 伺服器中，您可以隨時使用 **虛擬快遞箱** 向在線或離線的玩家寄送物品包裹。收件人上線後即可開啟快遞箱隨時領取！

---

## 🎮 開啟與使用方式

您可以使用以下指令或在 `/menu` 選單中開啟：

```bash
# 開啟虛擬快遞箱 GUI
/express

# 選單快捷入口
/menu -> 點選 [📦 虛擬快遞箱]
```

---

## 💡 三大選單功能說明

1. **✉️ 寄送包裹 (Send Package)**：
   - 點擊開啟 9x6 虛擬寄件箱子。
   - 將您想要寄出的物品放入箱子槽位中。
   - 選擇或輸入目標玩家名稱，點擊確認即可完成寄件！
   - 無論對方是否在線，系統都會將包裹安全送到對方的收件箱。

2. **📦 離線收件箱 (Inbox)**：
   - 開啟您的個人收件箱，查看其他人寄給您的包裹清單。
   - 點擊包裹即可將裡面的物品安全一鍵放入背包。

3. **📜 寄件紀錄 (History)**：
   - 查看您過去寄出物品的時間、收件人與包裹內容紀錄。
