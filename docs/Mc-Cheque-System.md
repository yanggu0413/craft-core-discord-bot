# 📜 實體銀行支票系統指南

Craft-Core 提供了真實、可實體化的 **銀行支票系統 (Bank Cheque System)**。玩家可以將個人戶頭中的金幣轉化為具備防偽標籤的實體紙張支票，放在背包、交易給其他玩家、存入箱子，甚至經由漏斗與發射器等紅石機關自動傳輸！

---

## 🎮 指令與選單開啟

```bash
# 開啟支票開立中心 GUI
/check
/cheque

# 自訂金額開立支票
/check <面額金額>
/cheque <面額金額>
/check write <面額金額>

# 範例：開立 $2,500 元支票
/check 2500
```

---

## 📜 支票物品特性與防偽機制

1. **實體物品屬性**：
   - 支票為真實的 `紙張 (Paper)` 物品，帶有耀眼的**附魔閃爍光澤 (Glint)**。
   - 可存放在個人背包、末影箱、密碼箱、快遞箱中，或丟棄至地面與他人面交。
   - 完全支援紅石漏斗傳輸、箱子分類機與發射器發射。
2. **高強度 NBT 防偽標籤**：
   - 每張支票物品均寫入不可偽造的 `craftcore_check` NBT 數據。
   - 紀錄資訊包含：`開票人名稱`、`面額金額`、`開票時間` 與 `8 位數防偽流水號 (#CHK-XXXXXX)`。
   - 任何嘗試使用鐵砧重命名或冒充的物品皆無法通過防偽驗證，絕對安全。

---

## 💳 支票兌現流程

1. 手持支票物品按 **【右鍵】**（對著空氣或方塊點擊均可）。
2. 畫面彈出 **📜 支票兌現確認** 二級選單。
3. 點擊 **`✅ 確認兌現支票`**。
4. 系統自動扣除手上 1 張支票物品，並將金額即時存入您的個人戶頭（伴隨清脆的金幣音效）！
