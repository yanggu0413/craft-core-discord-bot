# 🎖️ 頭頂炫彩稱號與標籤選單

展現您的尊貴榮譽！在 Craft-Core 中，玩家可透由完成機器認證、野外尋寶、全服目標、幸運錦鯉或累積財富解鎖各式炫彩稱號。

---

## 🎮 稱號指令說明

```bash
# 查看自己已解鎖的所有稱號清單與當前佩戴稱號
/title

# 佩戴指定的已解鎖稱號 (支援 <Tab> 自動補全選單樣式碼)
/title set <稱號名稱>

# 卸下當前佩戴的頭頂稱號 (回復原始 LuckPerms 身分組頭銜如 [服主 Owner] / [管理員 Admin])
/title clear  (或 /title reset / /title remove / /title off)
```

> **提示 1**：輸入 `/title set ` 並按下 **`<Tab>` 鍵**，系統會自動列出您目前所有已解鎖的稱號樣式碼與名稱，直接點選或補全即可佩戴！  
> **提示 2**：抽中整點活動「幸運錦鯉」僅會將稱號 **解鎖至您的稱號選單中**，不會自動強行覆蓋您原本的 [服主 Owner] 或 [管理員 Admin] 身分組頭銜！
