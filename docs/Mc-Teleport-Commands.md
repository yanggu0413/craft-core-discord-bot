# 🤝 玩家轉帳與傳送指令指南

Craft-Core 提供了完整的玩家對點傳送、家園傳送、公共地標與安全的金幣轉帳機制。所有聊天互動均配備一鍵式按鈕，操作安全便捷。

---

## 👥 1. 玩家傳送請求 (/tpa)

```bash
# 向指定線上玩家發送對點傳送請求
/tpa <玩家名稱>

# 接受來自該玩家的傳送請求
/tpaccept

# 拒絕來自該玩家的傳送請求
/tpdeny
```

- **聊天欄按鈕響應**：當收到傳送請求時，受請求玩家會在聊天欄看到帶有 `[✔ 點擊接受]` 與 `[❌ 點擊拒絕]` 的顏色按鈕，直接點擊即可完成響應，無須鍵入文字。

---

## 💸 2. 玩家安全轉帳 (/pay)

```bash
# 向指定線上玩家轉帳金幣
/pay <玩家名稱> <金額>
```

- **安全按鈕確認機制**：選取玩家並輸入金額後，系統會在聊天欄彈出 `[✔ 點擊確認轉帳]` 按鈕。玩家必須親自點擊按鈕才會扣除餘額並發送資金，徹底防止誤按或打錯數字。

---

## 🏠 3. 個人家園傳送 (Homes)

```bash
# 設定家園傳送點
/sethome <家名稱>

# 傳送至家園
/home <家名稱>

# 刪除家園
/delhome <家名稱>
```

- **家園額度說明**：每位玩家預設享有 2 個免費家園設定額度。設定同名家園更新位置完全免費。

---

## 🏁 4. 基礎與公共傳送指令

- **`/warp <地標>`**：傳送至公共地標（如 `/warp spawn`）。
- **`/rtp`**：隨機傳送至野外安全地點。
- **`/back`**：傳送回上一次的傳送位置或死亡地點。
