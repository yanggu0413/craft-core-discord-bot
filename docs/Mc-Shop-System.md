# 🏪 箱子商店與全服市場指南

Craft-Core 擁有直觀便利的 **箱子商店與全服市場系統**。玩家可以自己擺攤賺錢，也可以在選單中瀏覽全伺服器所有玩家的公開商店並一鍵傳送！

---

## 🎮 開啟方式

```bash
# 開啟商店市場與管理選單
/shop

# 選單快捷入口
/menu -> 點選 [🏪 商店管理系統]
```

---

## 💡 核心功能說明

1. **🛒 全服箱子商店市場**：
   - 查看全服公開營運中的箱子商店清單。
   - 支援商品名稱過濾與搜尋，點擊商店即可付費傳送至店家現場購物。

2. **🏪 店主遙控台**：
   - 瀏覽您個人擁有的所有商店與放置座標。
   - 查看累積的營業額收益，並可於選單中一鍵提領金幣至個人帳戶。

3. **發光告示牌與物品展示**：
   - 建立商店時自動貼上高亮發光告示牌與物品立體模型，買賣價格一目了然。
