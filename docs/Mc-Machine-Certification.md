# 🏭 機器認證與免領地費指南

Craft-Core 鼓勵玩家建造大型自動化紅石與農業設施，同時透過 **機器認證機制** 提供領地維護費用減免福利。

---

## 🎮 申請與審核流程

1. **站在設施領地內提交申請**：
   站在您建造完成的自動化設施領地內，輸入以下指令或在選單中點擊：
   ```bash
   # 提交機器審核申請
   /machine apply

   # 選單快捷入口
   /menu -> 點選 [🏭 機器認證與免領地費]
   ```
2. **填寫說明並送交審核**：
   填寫設施名稱與用途說明，系統會自動記錄您所在的座標與領地。
3. **管理員原生 GUI 面板審核**：
   管理員開啟控制台後，可透過直觀的選單面板直接一鍵傳送至設施現場，確認後可一鍵點擊批准 T1 / T2 / T3 等級或進行駁回。

---

## 💡 認證權益說明

- **T1 認證**：基礎認證標籤。
- **T2 / T3 認證**：獲得**免領地維護費**福利，領地不會因時間或費用未繳而被系統清除。
