# 🏭 機器認證與免領地維護費系統

為了鼓勵玩家設計並建造高效率的自動化紅石機器、農場與工業巨構，Craft-Core 推出 **「機器認證評級與免領地費」** 獎勵機制！

---

## 📜 機器認證等級與特權

經過管理員 (OP) 審核核准後，您的機器將獲得相應的評級與專屬權益：

| 認證等級 | 機器類型說明 | 審核通過專屬獎勵與權益 |
|---|---|---|
| **T1 基礎農場** | 小型半自動/自動化作物農場 | **免除 50% 領地維護費用** |
| **T2 自動化工程** | 大型自動化紅石工程、刷鐵機、刷怪塔 | **100% 免除領地費 (Free Claim)** + 解鎖稱號 `§b[🏭 工業大亨]` |
| **T3 傳奇工業巨構** | 全服頂級複合式自動化工業工程 | **100% 免除領地費 (Free Claim)** + 解鎖頂級稱號 `§6[⚙️ 首席工程師]` |

## 🎮 玩家申請與管理員審核指令

### 1. 玩家申請認證
站在您建造好機器的領地範圍內，執行：
```bash
/machine apply <機器名稱與簡述>
```
*系統將自動記錄該機器的座標、維度與申請時間，並送交管理員審核清單。*

### 2. 管理員 (OP) 審核指令
```bash
# 查看所有待審核的機器申請清單
/machine admin list

# 核准機器申請並授予等級 (T1 / T2 / T3)
/machine approve <申請ID> <T1|T2|T3>

# 駁回機器申請
/machine reject <申請ID>
```

## 🌐 網頁儀表板展示 (Web Machine Registry)

所有通過認證的機器將自動同步登錄於 Web Dashboard 的 **「🏭 官方認證機器名冊」**，展示機器名稱、擁有者、認證等級與座標，供全服玩家前去參觀與觀摩！
