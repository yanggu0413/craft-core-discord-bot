# 📜 /menu 選單大廳指南

Craft-Core 提供了全方位視覺化的箱子選單大廳。您只需要輸入 `/menu` 即可開啟擁有 4x4 完美分類對稱網格的大廳介面，輕鬆體驗伺服器的所有功能。

---

## 🎮 開啟方式與指令

```bash
# 開啟選單大廳
/menu

# 快捷別名
/m
/cd
```

---

## 🧭 4x4 清爽分類網格架構

開啟選單大廳後，介面分為四大部分：

```
[第 2 列 - 核心功能] 🏪 商店管理系統 | 🧭 傳送與家園 | 🌿 領地與密碼箱 | 📦 虛擬快遞箱
[第 3 列 - 社交金流] 🤝 玩家傳送請求 | 💸 玩家安全轉帳 | ⚔️/🪬 PvP 戰鬥切換 | 💬 Discord 社群
[第 4 列 - 活動統計] 🎰 福利中心     | ⚔ 任務與懸賞 | 🏆 全服排行榜   | 🏭 機器認證與免領地費
[第 5 列 - 工具管理] 🤖 假人控制台   | 🛠️ 管理員控制台| 🗑️ 隨身垃圾桶
```

---

## 💡 選單功能介紹

| 功能圖示 | 選單名稱 | 點擊效果說明 |
|---|---|---|
| 🏪 `商店管理系統` | 全服商店與遙控 | 點擊開啟 `/shop`，瀏覽全服商店市場與提領個人擺攤收益。 |
| 🧭 `傳送與家園` | 家園與地標傳送 | 列出個人所有家點、公共地標、一鍵隨機傳送 (`/rtp`) 與返回死亡點 (`/back`)。 |
| 🌿 `領地與密碼箱` | 領地劃分與保險箱 | 管理個人領地、獲取圈地木斧以及箱子密碼鎖設定 (`/padlock`)。 |
| 📦 `虛擬快遞箱` | 跨服與離線包裹 | 開啟寄件箱與收件箱，向線上或離線玩家寄送物品 (`/express`)。 |
| 🤝 `玩家傳送請求` | 線上玩家對點傳送 | 點擊開啟線上玩家頭顱列表，一鍵發送對點傳送請求 (`/tpa`)。 |
| 💸 `玩家安全轉帳` | 玩家金幣轉帳 | 點擊選擇目標玩家，於聊天欄輸入金額並進行一鍵按鈕確認轉帳 (`/pay`)。 |
| 🪬/⚔️ `PvP 戰鬥狀態` | 和平與戰鬥保護 | 一鍵切換個人 PvP 狀態（預設和平保護，免受他人攻擊）。 |
| 💬 `Discord 社群` | 社群連結與綁定 | 獲取官方 Discord 邀請連結或生成 6 位數帳號綁定碼 (`/discord link`)。 |
| 🎰 `福利中心` | 簽到與轉盤抽獎 | 每日簽到領獎、在線時數兌換鑰匙與 9x3 幸運轉盤抽獎。 |
| ⚔ `任務與懸賞` | 每日任務與寶藏 | 查看每日擊殺挖掘任務、全服共同大目標與野外藏寶圖線索。 |
| 🏆 `全服排行榜` | 財富與簽到排行 | 查看全服財富 Top 10、抽獎鑰匙 Top 10 與連續簽到排行榜。 |
| 🏭 `機器認證` | 免領地費申請 | 站在自動化機器領地內點擊一鍵提交審核申請 (`/machine apply`)。 |
| 🤖 `假人控制台` | 助手召喚與看管 | 召喚假人、切換掛機打怪/挖掘動作、以及查看假人背包。 |
| 🗑️ `隨身垃圾桶` | 物品銷毀垃圾桶 | 開啟 10 秒自動銷毀隨身垃圾桶 (`/wastebin`)。 |

---

## ⭐ 特點

1. **直覺操作**：所有功能點擊即可開啟對應子選單，無需記憶繁瑣指令。
2. **完整指令相容**：所有指令（如 `/shop`, `/claim`, `/home`, `/rtp`, `/pay`, `/tpa`, `/pvp`, `/express` 等）皆 100% 完整保留，習慣鍵入指令的玩家隨時可以使用。
