# 📜 /menu 選單大廳指南

Craft-Core 提供了全方位視覺化的箱子選單大廳。您只需要輸入 `/menu` 即可開啟擁有 **4 直排 (4 Vertical Columns)** 完美對齊分類的大廳介面，輕鬆體驗伺服器的所有功能。

---

## 🎮 開啟方式與指令

```bash
# 開啟選單大廳
/menu

# 快捷別名
/m
/cd
```

---

## 🧭 四直排 (4 Vertical Columns) 視覺化架構

開啟選單大廳後，所有功能圖示依據性質精確歸類於 **4 個直排 (Col 2, Col 4, Col 6, Col 8)** 中：

```
【直排 1 - 核心經濟】 🏪 商店管理系統 ➔ 📜 銀行支票中心 ➔ 📦 虛擬快遞箱 ➔ 🗑️ 隨身垃圾桶
【直排 2 - 傳送保全】 🧭 傳送與家園   ➔ 🛡️ 領地與密碼箱 ➔ 🤝 玩家 TPA 傳送 ➔ ⚔️ PvP 戰鬥切換
【直排 3 - 社群福利】 🎰 福利中心     ➔ ⚔️ 每日任務懸賞 ➔ 🏆 全服排行榜   ➔ 💬 Discord 社群
【直排 4 - 控制工具】 🤖 假人控制台   ➔ 🏭 機器認證申請 ➔ 🛠️ 管理員控制台 ➔ 📖 說明指南 (/help)
```

## 💡 選單功能介紹

| 功能直排 | 選單圖示 | 選單名稱 | 點擊效果說明 |
|---|---|---|---|
| **直排 1** | 🏪 | `商店管理系統` | 點擊開啟 `/shop`，瀏覽全服商店市場與提領個人擺攤收益。 |
| **直排 1** | 📜 | `銀行支票中心` | 點擊開啟 `/check` 支票開立中心，開立實體可交易紙張支票。 |
| **直排 1** | 📦 | `虛擬快遞箱` | 開啟寄件箱與收件箱，向線上或離線玩家寄送物品 (`/express`)。 |
| **直排 1** | 🗑️ | `隨身垃圾桶` | 開啟 10 秒自動銷毀隨身垃圾桶 (`/wastebin`)。 |
| **直排 2** | 🧭 | `傳送與家園` | 列出個人所有家點、公共地標、一鍵隨機傳送 (`/rtp`) 與死亡點 (`/back`)。 |
| **直排 2** | 🛡️ | `領地與密碼箱` | 管理個人領地、獲取圈地木斧以及箱子密碼鎖設定 (`/padlock`)。 |
| **直排 2** | 🤝 | `玩家傳送請求` | 點擊開啟線上玩家頭顱列表，一鍵發送對點傳送請求 (`/tpa`)。 |
| **直排 2** | ⚔️ | `PvP 戰鬥狀態` | 一鍵切換個人 PvP 狀態（預設和平保護，免受他人攻擊）。 |
| **直排 3** | 🎰 | `福利中心` | 每日簽到領獎、在線時數兌換鑰匙與 9x3 幸運轉盤抽獎。 |
| **直排 3** | ⚔️ | `任務與懸賞` | 查看每日擊殺挖掘任務、全服共同大目標與野外藏寶圖線索。 |
| **直排 3** | 🏆 | `全服排行榜` | 查看全服財富 Top 10、抽獎鑰匙 Top 10 與連續簽到排行榜。 |
| **直排 3** | 💬 | `Discord 社群` | 獲取官方 Discord 邀請連結或生成 6 位數帳號綁定碼 (`/discord link`)。 |
| **直排 4** | 🤖 | `假人控制台` | 開啟假人選單，一鍵召喚/解散假人、切換掛機動作與查看背包。 |
| **直排 4** | 🏭 | `機器認證` | 站在自動化機器領地內點擊一鍵提交審核申請 (`/machine apply`)。 |
| **直排 4** | 🛠️ | `管理員控制台` | (OP 專屬) 全服玩家背包監看、機器審核與地圖備份。 |
| **直排 4** | 📖 | `伺服器指南` | 聊天欄傳送高質感點擊連結前往線上說明文件 (`https://docs.craft-core.xyz`)。 |
