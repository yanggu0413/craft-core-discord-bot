# 📜 /menu 54-槽位箱子選單 GUI 系統指南

Craft-Core 提供了全方位視覺化 **54-槽位 (6x9) 箱子選單 GUI 系統**。將模組的所有功能（商店、領地、傳送、任務、懸賞、稱號、假人控制與管理員面板）全數整合於視覺化 GUI 介面中，**同時 100% 完整保留所有原版文字指令**。

---

## 🎮 指令與開啟方式

```bash
# 開啟 54-槽位選單大廳 GUI
/menu

# 指令別名 (功能完全相同)
/m
/cd
```

---

## 🧭 八大主選單分類 (54-Slot Hub Layout)

開啟 `/menu` 主選單後，介面中央將呈現八大功能選單面板：

```
[ Row 1 ] 🧱 灰色玻璃板裝飾邊框
[ Row 2 ] 🏪[10] 商店管理    🛡️[12] 領地/密碼鎖   🧭[14] 傳送與家園   ⚔️[16] 任務與懸賞
[ Row 3 ] 🧱 裝飾分隔
[ Row 4 ] 🎰[28] 福利與稱號  🤖[30] 假人控制台    🏭[32] 機器認證    🛠️[34] 管理員面板 (OP專屬)
[ Row 5 ] 🧱 裝飾分隔
[ Row 6 ] ❌[49] 關閉選單
```

| 圖示按鈕 | 類別名稱 | 點擊動作與子選單功能 |
|---|---|---|
| 🏪 `Slot 10` | **商店管理系統** | 導向遠端商店遙控 (`/shop control`)，查看全服擺攤、庫存與營收。 |
| 🛡️ `Slot 12` | **領地與密碼箱** | 導向領地列表 (`/claim list`)，查看領地座標、權限設定與保險箱。 |
| 🧭 `Slot 14` | **傳送與家園** | 列表展出個人所有家點 (`/home`)、公共地標 (`/warp`)、一鍵隨機傳送 (`/rtp`) 與返回死亡地點 (`/back`)。 |
| ⚔️ `Slot 16` | **任務與懸賞** | 查看每日任務 (`/task`)、全服每週大目標 (`/bounty`) 進度條與野外藏寶圖線索 (`/treasure`)。 |
| 🎰 `Slot 28` | **福利與頭頂稱號** | 直觀列出所有已解鎖頭頂稱號，**點擊即時佩戴/切換** (`/title`)。 |
| 🤖 `Slot 30` | **假人 (Bot) 控制台** | 一鍵召喚新假人、一鍵開啟假人 54-槽位背包 (`/invsee`)、切換自動打怪或解散假人。 |
| 🏭 `Slot 32` | **機器認證與免領地費** | 站在機器領地內點擊一鍵提交機器審核 (`/machine apply`)，查看 T2/T3 免領地費狀態。 |
| 🛠️ `Slot 34` | **管理員 (OP) 控制台** | *(僅 OP 可見)* 一鍵開啟全服玩家/假人 `/invsee` 選擇器、機器認證審核面板與 7z 手動地圖備份。 |

## ⭐ 特色與指令相容性

1. **即點即觸發 (Instant Action)**：
   在子選單中點擊家園或地標，即時觸發傳送；點擊稱號即時切換頭頂標籤；點擊假人即時開啟背包，無需手動輸入繁瑣參數。
2. **完整指令保留 (Full Command Compatibility)**：
   所有原版文字指令（如 `/shop`, `/claim`, `/home`, `/warp`, `/bounty`, `/treasure`, `/title`, `/invsee`, `/bot` 等）皆 100% 完整保留，習慣打字的玩家依然可以隨時鍵入指令！
