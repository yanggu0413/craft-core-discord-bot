# 🗺️ 野外藏寶圖與地城寶箱系統

為了讓野外探險更加刺激，Craft-Core 設有 **自動野外寶箱刷新與探險廣播機制**。玩家可根據線索前往野外尋寶，獲取豐富獎勵與稱號！

---

## 🧭 寶箱刷新與廣播機制

1. **每 2 小時隨機刷新**：
   伺服器每隔 2 小時會在野外（主世界未被玩家圈地保護的區域）自動生成一個「神秘藏寶箱」。
2. **座標區塊提示**：
   寶箱刷新時，伺服器會向全服玩家廣播大致座標範圍提示（例如：`X: 1200 ~ 1500, Z: -600 ~ -300`）。
3. **查詢最新線索**：
   玩家可隨時在遊戲內執行：
   ```bash
   /treasure
   ```
   即可在聊天室中重新獲得當前活躍寶箱的大致座標線索與區域提示！

---
