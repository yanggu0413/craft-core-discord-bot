# 🗺️ 野外定向尋寶雷達指南

為了讓野外探險更加刺激且兼具探索成就感，Craft-Core 設有 **野外寶箱地表刷新與定向羅盤尋寶系統**。玩家可根據區域廣播與羅盤雷達提示前往野外尋寶，預計搜尋時間約 **10～25 分鐘**，獲取豐富金幣、抽獎鑰匙與專屬稱號！

---

## 🧭 寶箱刷新與定向雷達機制

1. **每 2 小時隨機地表刷新**：
   伺服器每隔 2 小時會在主世界野外地表（`Y >= 60`）自動生成一個「神秘藏寶箱」，絕不落入基岩或地底深穴。
2. **45 秒定時天空聲納脈衝**：
   寶箱不會發出 24 小時永久光柱，而是**每隔 45 秒向天空發射短暫 3 秒鐘的黃金聲納脈衝光束**。探險時請注意觀察遠方天空的瞬閃光柱！
3. **100x100 區域廣播**：
   寶箱刷新時，全服廣播會給出精確縮小至 `100x100` 方塊的搜尋分區（例如：`X: 100 ~ 200, Z: 500 ~ 600`）。
4. **25 公尺近距離感應粒子**：
   只有當玩家接近寶箱 **25 公尺以內** 時，寶箱四周才會散發出微弱的金色粒子微光，協助您在草叢或岩石旁定位寶箱。
5. **🧭 定向羅盤尋寶雷達 (`/treasure`)**：
   玩家隨時可以輸入指令或在 `/menu` 中點擊藏寶圖：
   ```bash
   /treasure
   ```
   * **10 秒個人冷卻時間**：雷達具備 10 秒防洗指令冷卻。
   * **動態距離與方位提示**：
     - **> 300 公尺**：提示 100x100 廣域分區與大致方位。
     - **100 ~ 300 公尺**：開啟羅盤中程感應，提供動態區段距離（如：`東北方向 約 150~200 公尺`）。
     - **25 ~ 100 公尺**：觸發強烈熱感應與近距離提醒。
     - **< 25 公尺**：極熱感應提醒，寶箱就在身邊 25 公尺內！
