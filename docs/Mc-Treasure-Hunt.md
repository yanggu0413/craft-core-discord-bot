# 🗺️ 野外定向尋寶雷達指南

為了讓野外探險更加刺激，Craft-Core 設有 **自動野外寶箱刷新與定向羅盤尋寶系統**。玩家可根據雷達提示前往野外尋寶，獲取豐富金幣、抽獎鑰匙與專屬稱號！

---

## 🧭 寶箱刷新與定向雷達機制

1. **每 2 小時隨機刷新**：
   伺服器每隔 2 小時會在主世界野外自動生成一個「神秘藏寶箱」，天空會升起極為密集的金色粒子光柱。
2. **100x100 精確網格縮小**：
   寶箱刷新時，全服廣播會給出精確縮小至 `100x100` 方塊的搜尋區域（例如：`X: 100 ~ 200, Z: 500 ~ 600`）。
3. **🧭 定向羅盤尋寶雷達 (`/treasure`)**：
   玩家隨時可以輸入指令或在 `/menu` 中點擊藏寶圖：
   ```bash
   /treasure
   ```
   系統會根據您當前的位置即時提供 **方向與距離雷達提示**：
   - **遠距離 (>300 公尺)**：顯示 100x100 區域範圍與預估距離。
   - **中距離 (35 ~ 300 公尺)**：開啟羅盤感應，精確提示方位與距離（例如：`寶箱在您的 ↗ 東北 方向，距離約 120 公尺 (高度 Y: 68)`）。
   - **近距離 (<35 公尺)**：觸發強烈熱感應（例如：`寶箱就在您 ⬇ 正南 方向僅 15 公尺！(高度 Y: 68)`）。
