# ⚔️ PvP 和平與戰鬥模式指南

Craft-Core 伺服器尊重每位玩家的生存風格，提供 **雙向開關的 PvP 戰鬥與和平保護機制**。

---

## 🎮 切換模式方式

您可以使用以下指令或在 `/menu` 選單中自由切換：

```bash
# 切換 PvP 狀態
/pvp

# 選單快捷入口
/menu -> 點選 [⚔️ PvP 戰鬥狀態]
```

---

## 💡 模式規則說明

1. **🛡️ 和平保護模式 (預設)**：
   - 預設所有人皆處於和平保護模式。
   - 在此模式下，您免受任何玩家的攻擊傷害，同時您也無法攻擊其他玩家。
   - 適合專心建築、採礦與探索生存的玩家。

2. **⚔️ 戰鬥模式**：
   - 當您主動開啟 `/pvp` 後，將進入戰鬥狀態。
   - **雙向同意原則**：只有在**雙方玩家都開啟 `/pvp`** 的情況下才能進行對決。開啟 PvP 的玩家無法攻擊處於和平保護模式的玩家。
