# 🌐 全服共同目標與每週懸賞

全服玩家心連心！Craft-Core 設有 **「全服每週共同目標 (Global Community Goal)」**，邀請全體玩家共同合作達成挑戰，解鎖全服大紅包與專屬稱號！

---

## 🎯 共同目標運作機制

1. **每週一自動刷新大目標**：
   例如全服玩家共同擊殺 3,000 隻怪物、採集 2,000 顆深層鑽石或捕獲 1,000 條魚。
2. **進度實時累加**：
   所有玩家在遊戲內打怪、採集或釣魚時，個人貢獻與全服總進度會實時累加。
3. **查詢目標與貢獻榜**：
   在遊戲內執行：
   ```bash
   /bounty
   ```
   即可查看當前目標名稱、全服進度百分比（如 `78.5%`）以及目前貢獻第一名的玩家名稱。

---

## 🏆 全服結算獎勵

當全服進度達到 **100%** 時：

- 🎁 **全服參與玩家發放獎勵**：所有有貢獻的玩家將自動領取 **$1,000 元金幣 + 2 把幸運鑰匙**！
- 👑 **貢獻榜冠軍獎勵**：個人貢獻第一名的玩家將額外解鎖限定頭頂稱號 `§c[全服英雄]`！
