# 管理員權限與維護指南

本指南列出 Craft-Core 伺服器管理員專用的遊戲內指令、Ledger 方塊紀錄查詢回滾系統，以及 Discord 管理員控制面板說明。

---

## 1. /ledger (/lg) 方塊紀錄查詢與回滾還原系統

伺服器配備了強大的 **Ledger 方塊與防破壞紀錄系統**，管理員可透過 `/ledger`（快捷別名 `/lg`）隨時查詢方塊歷史變動或進行一鍵復原。

### 🔍 檢查模式 (Inspect Mode)
- **`/lg inspect`** 或 **`/lg inspect [on|off]`**：開啟或關閉檢查模式。
- **使用方式**：開啟檢查模式後，對著目標方塊按**【左鍵】**或**【右鍵】**，聊天欄會即時顯示該方塊是誰在什麼時間點放置、破壞，或是誰拿走了容器內的物品。

### 🔎 日誌搜尋 (Search)
- **`/lg search <參數>`**：依據條件搜尋記錄而不進行變更。
- **範例**：`/lg search source:Alex time:1h range:10`（查詢玩家 Alex 在近 1 小時內於 10 格範圍內的所有動作）。

### ↩️ 一鍵回滾還原 (Rollback)
- **`/lg rollback <參數>`**：依據條件將指定範圍內被破壞或變更的方塊一鍵恢復至原狀。
- **範例**：`/lg rollback source:BadPlayer time:2h range:20`（將近 2 小時內被 BadPlayer 在 20 格內破壞的方塊全部還原）。

### 🛠️ 常用過濾參數說明
- **`source:<玩家/實體>`**：指定操作者名稱（如 `source:Alex` 或爆炸來源 `source:tnt`）。
- **`time:<時間>`**：指定時間範圍（如 `1h` 一小時內、`1d` 一天內）。
- **`range:<距離>`**：指定管理員身邊半徑內的範圍格數（如 `range:15`）。
- **`action:<動作>`**：指定動作類型（如 `block-break` 破壞方塊、`block-place` 放置方塊、`container-change` 容器物品存取）。

### 🔄 撤銷與取消操作
- **`/lg undo`** 或 **`/lg restore`**：若還原範圍設定有誤，可一鍵撤銷上一次的回滾復原動作。

## 2. 遊戲內管理員專用指令

| 指令 | 功能說明 | 範例與備註 |
| :--- | :--- | :--- |
| **`/addmoney <玩家> <金額>`** | 增加指定玩家的遊戲金幣餘額 | `/addmoney Alex 5000` |
| **`/removemoney <玩家> <金額>`** | 扣除指定玩家的遊戲金幣餘額 | `/removemoney Alex 1000` |
| **`/setwarp <地標名稱>`** | 在當前位置建立公共地標 | `/setwarp spawn` |
| **`/delwarp <地標名稱>`** | 刪除指定的公共地標 | `/delwarp spawn` |
| **`/invsee <玩家>`** | 查看與編輯線上玩家或假人的背包與裝備箱 | `/invsee Alex` |
| **`/ban <玩家> [原因]`** | 封鎖指定玩家並禁止登入 | `/ban BadUser 破壞地形` |
| **`/kick <玩家> [原因]`** | 強制踢出指定線上玩家 | `/kick AFKUser 佔用伺服器` |
| **`/shop list`** | 列出全服所有註冊商店 | `/shop list` |
| **`/shop reload`** | 重新載入商店設定與資料 | `/shop reload` |

## 3. 管理員無限系統商店

管理員可建立免庫存、免資金的官方系統商店：
1. 建立商店後，對著商店告示牌按**【右鍵】**開啟管理面板。
2. 管理員可看見**「切換無限」**按鈕，點擊後庫存將切換為無限模式，玩家可自由買賣。
3. 對著無限商店面板點選**「清空箱子」**按鈕，可快速清空實體箱子內的殘留物品。

## 4. Discord 管理員控制面板

管理員可於 Discord 專屬維護頻道中使用以下快捷面板：
- **封鎖/踢出玩家**：填寫玩家 ID 與理由發送處分。
- **發布全服公告**：預覽並發布彩色全服公告訊息。
- **公共設施審核**：審核玩家提交的設施申請，點擊同意後自動設立 `/warp` 地標。
