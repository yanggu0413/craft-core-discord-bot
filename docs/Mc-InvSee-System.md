# 🔍 /invsee 玩家與假人背包管理系統

Craft-Core 提供了原生 26.2 54-槽位實時雙向背包與裝備管理介面。無論是管理員進行維護與沒收，或是普通玩家管理自己創建的假人 (Bot)，皆可透由 `/invsee` 指令進行直觀操作。

---

## 🎮 指令與權限說明

| 指令 | 適用對象 | 功能與權限 |
|---|---|---|
| `/invsee <玩家/假人名稱>` | 普通玩家 | **僅限查看與拿取自己擁有的假人**（使用 `/bot` 召喚之 Bot）背包物品與裝備。 |
| `/invsee <玩家/假人名稱>` | OP 管理員 | 可檢視與拿取全服所有線上/離線玩家及假人的背包、裝備、末影箱與狀態。 |

---

## 📦 54 槽位介面版面配置 (UI Layout)

開啟 GUI 後，將呈現 6x9 (54 格) 大型箱子容器：

```
[ Slot 0  ~ 35 ] 🎒 主背包 36 格空間 (快捷欄 + 物品欄)
[ Slot 36 ~ 39 ] 🛡️ 裝備欄位 (頭盔、胸甲、護腿、靴子)
[ Slot 40      ] 🗡️ 副手 (Offhand) 裝備格
[ Slot 41 ~ 43 ] 📊 玩家實時狀態 (❤️ 生命值 / 🍖 飽食度 / 💰 金幣餘額)
[ Slot 44      ] 🟣 末影箱切換按鈕 (一鍵切換 主背包 ↔ 末影箱)
[ Slot 45 ~ 53 ] 🔒 控制與隔離欄位
```

---

## ⭐ 特色與安全保護機制

1. **實時雙向同步 (Two-way Realtime Sync)**：
   在 GUI 內移動、放置或拿出物品時，目標玩家/假人身上的物品會**瞬間同步更新**，無需關閉介面。
2. **末影箱切換 (Ender Chest Toggle)**：
   點擊 Slot 44 的 🟣 紫色末影水晶圖示，即可切換檢視與管理目標玩家的末影箱內容！
3. **離線 NBT 讀寫支援**：
   若目標玩家目前不居於線上記錄，系統自動解析 `PlayerData NBT` 進行離線讀寫。
4. **管理員沒收通知與日誌審核**：
   當管理員從普通玩家背包拿取或調整物品時，系統會自動在遊戲內向目標玩家發送黃字提醒，並寫入系統防作弊日誌 `logs.json`。
